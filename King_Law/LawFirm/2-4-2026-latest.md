## Key Learnings

### Svelte 5 Migration Patterns

1. **Event dispatching → Callback props**
   ```svelte
   // Old (Svelte 4)
   const dispatch = createEventDispatcher();
   dispatch('select', file);
   
   // New (Svelte 5)
   let { onselect }: { onselect?: (file: File) => void } = $props();
   onselect?.(file);
   ```

2. **DOM element refs need $state for null safety**
   ```svelte
   // Correct
   let element = $state<HTMLDivElement | null>(null);
   ```

3. **Prop reactivity requires $effect**
   ```svelte
   let { open = false } = $props();
   let isOpen = $state(false);
   $effect(() => { isOpen = open; });
   ```

### Drizzle ORM / SQLite

- SQLite stores timestamps as **integers** (Unix seconds), not Date objects
- Always convert: `Math.floor(Date.now() / 1000)` when inserting
- Convert back: `new Date(timestamp * 1000)` when displaying

### SvelteKit

- Don't use `.ts` extension when importing `.svelte.ts` files
- `redirect()` **throws**, doesn't return - no need to return its result
- Vercel adapter provides `x-vercel-ip-country` header for geo-blocking

### CSP Headers (To Implement)

Content Security Policy prevents XSS by whitelisting trusted sources:
```typescript
// In hooks.server.ts
response.headers.set('Content-Security-Policy', 
  "default-src 'self'; script-src 'self'; style-src 'self' 'unsafe-inline';"
);
```

### Geo-Blocking (To Implement)
